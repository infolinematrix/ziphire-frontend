## Getting Started

To get started, install dependencies and run the development server:

```bash
npm install
npm run dev
# or
yarn install
yarn dev
# or
pnpm install
pnpm dev
# or
bun install
bun dev

## Project Structure

```
frontend/
├── app/                # Main application routes and pages (Next.js App Router)
│   └── page.tsx        # Main landing page
├── components/         # Reusable React components (e.g., JobCard, Navbar)
├── public/             # Static assets (images, icons, etc.)
├── styles/             # Global and modular CSS/SCSS files
├── utils/              # Utility functions and helpers
├── package.json        # Project metadata and dependencies
├── next.config.js      # Next.js configuration
└── README.md           # Project documentation
```

- **app/**: Contains all route segments and pages for the app.
- **components/**: Houses UI components used throughout the project.
- **public/**: Stores static files served at the root.
- **styles/**: Contains global styles and CSS modules.
- **utils/**: Utility/helper functions for the app.
- **package.json**: Lists dependencies and scripts.
- **next.config.js**: Next.js configuration options.
